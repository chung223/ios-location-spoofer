# 用 iOS「快捷指令」一键改定位

[English](快捷指令一键改定位.en.md) · **中文**

配合 [`location-picker`](./) 使用。目标：不打开网页，**在主屏幕点一下 / 轻点手机背面**就切换定位。

---

## 先说清楚原理和限制（重要）

- 网页、PWA、快捷指令都**不能直接写入 iOS 的 GPS**。真正改定位的，是代理软件（Surge / 小火箭 / Loon）在半路改写 Apple 定位服务器（`gs-loc` / `wloc`）的回应。
- `location-picker` 的 `POST /set` 接口做的事就是：**把「要回给 iPhone 的坐标」存下来**。快捷指令直接打这个接口，就等于「不开网页也能改坐标」。
- 改完坐标后，iPhone 会先用**缓存的旧定位**，必须「逼」它重新向 Apple 请求才生效。
  - 快捷指令**无法**开关「定位服务」总开关（iOS 没有这个操作）。
  - 但快捷指令**可以**开关 **Wi-Fi / 飞行模式**。而 `wloc` 定位靠 Wi-Fi/基站扫描，切一下通常能触发 iPhone 重新请求 → 代理改坐标 → 新定位。
- ⚠️ **诚实提醒**：Wi-Fi/飞行模式触发**不是 100% 即时**，系统版本不同表现有差异，偶尔仍需**手动关开一次定位服务**。它能省掉大部分手动操作，但不能保证完全零操作。

---

## 前置条件

1. 已部署 `location-picker`（Cloudflare Worker 或自托管），拿到 **Worker 地址** 和 **TOKEN**。
2. 代理模块已配好 `configUrl`、MITM/证书正常（见仓库主教程 [`使用教程.md`](../使用教程.md) 和各平台 README）。
3. iPhone 自带的 **「快捷指令」(Shortcuts)** App。

> 先在浏览器打开 `https://你的worker/loc.json?token=你的TOKEN` 确认能读到坐标，再做下面的快捷指令。

---

## 一、单地点版（最简单，5 分钟）

打开「快捷指令」App → 右上角 **＋** 新建，依次添加这些操作：

1. **获取URL内容 (Get Contents of URL)**
   - **URL**：`https://你的worker.workers.dev/set?token=你的TOKEN`
   - 点开 **「显示更多」(Show More)**
   - **方法 (Method)**：`POST`
   - **请求体 (Request Body)**：选 **JSON**，加字段：
     | 键 (Key) | 类型 (Type) | 值 (Value) |
     |------|------|------|
     | `lat` | 数字 Number | `25.0339`（你的纬度） |
     | `lng` | 数字 Number | `121.5645`（你的经度） |
     | `altitude` | 数字 Number | 可选，目标地点海拔 |
     | `horizontalAccuracy` | 数字 Number | 可选，如 `10` |
     | `verticalAccuracy` | 数字 Number | 可选，如 `20` |
   - （JSON 请求体一般会自动带 `Content-Type: application/json`；若报错，手动在 Headers 加 `Content-Type = application/json`。）

2. **设定飞行模式 (Set Airplane Mode)** → **打开 (On)**
3. **等待 (Wait)** → **2** 秒
4. **设定飞行模式 (Set Airplane Mode)** → **关闭 (Off)**

   > 备选：用 **设定Wi-Fi (Set Wi-Fi)** 关 → 等 2 秒 → 开。两种触发法二选一，哪种在你机器上更灵就用哪种。

5. （可选）**显示通知 (Show Notification)** → 「已切换到 台北 101」

给快捷指令起个名字（如「定位 → 台北」）保存。

### 绑定触发方式（任选其一或多个）

- **主屏幕图标**：快捷指令详情 → 分享 → **添加到主屏幕**，变成一个 App 图标。
- **轻点背面**：设置 → 辅助功能 → 触控 → **轻点背面 (Back Tap)** → 轻点两下/三下 → 选这个快捷指令。（点两下手机背面就切定位）
- **操作按钮**（iPhone 15 Pro 起）：设置 → 操作按钮 → 快捷指令。
- **锁屏 / 主屏幕小组件**、或对 Siri 说快捷指令名字。

---

## 二、多地点选单版（一个快捷指令切多个地点）

1. 新建快捷指令，第一个操作加 **从菜单中选取 (Choose from Menu)**，菜单项写：`家`、`公司`、`台北101`、`东京塔`…
2. 在**每个菜单分支**里，放一份「一、单地点版」的 3 个操作（获取URL内容 + 切飞行模式），各自填该地点的 `lat`/`lng`。
3. 保存后绑定到背面轻点/主屏幕，点一下就弹出菜单选地点。

常用坐标（纬度在前、经度在后，可直接抄）：

| 地点 | lat | lng |
|------|------|------|
| 北京天安门 | 39.9087 | 116.3975 |
| 上海外滩 | 31.2397 | 121.4900 |
| 台北 101 | 25.0339 | 121.5645 |
| 东京塔 | 35.6586 | 139.7454 |

> 进阶：也可以用「词典 (Dictionary)」集中存多个坐标，再用变量取值，减少重复分支。

## 三、生效与排错

**改完没变？按顺序查：**

1. 打开 `https://你的worker/loc.json?token=你的TOKEN`，看经纬度**是否已经变了**。
   - **变了** → 接口成功，问题在「触发/缓存」：手动去**设置 → 隐私与安全性 → 定位服务**，关 10 秒再开，打开地图 App 看。
   - **没变** → 接口没打成功：检查快捷指令里的 **URL、TOKEN、`lat`/`lng`** 是否正确，方法是不是 POST。
2. Wi-Fi 触发不灵就换飞行模式，反之亦然；也可以两个都放（切 Wi-Fi + 切飞行模式）。
3. 确认代理模块的 `configUrl` 已加、MITM 开、CA 证书已「完全信任」（见主教程）。
4. 快捷指令联网失败：确认手机能正常上网；部分企业网络 / iCloud 私人转发偶尔会拦截，换网络重试。

---

## 四、安全提醒

- 快捷指令里**包含 TOKEN，等同你的密码**。不要把快捷指令、截图、iCloud 分享链接公开——iCloud 链接会带上 TOKEN。
- 只在自己的设备上用；换 TOKEN 后记得同步更新快捷指令里的 URL。

---

## 进阶：个人自动化（可选）

「快捷指令 → 自动化」里可以设**到达某地点**、**连接某 Wi-Fi**、**某个时间**时自动运行上面的快捷指令，做到「回家自动切到公司定位」这类效果。注意 iOS 对自动化默认会先弹确认，可在自动化设置里关掉「运行前询问」。
