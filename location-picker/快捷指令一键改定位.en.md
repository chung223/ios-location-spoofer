# One-Tap Location Change with iOS Shortcuts

**English** · [中文](快捷指令一键改定位.md)

Use together with [`location-picker`](./). Goal: change your spoofed location **from a Home Screen icon or a Back Tap**, without opening the web page.

---

## How it works & its limits (read first)

- Web pages, PWAs, and Shortcuts **cannot write iOS GPS directly**. The only thing that changes your location is the proxy (Surge / Shadowrocket / Loon) rewriting Apple's location responses (`gs-loc` / `wloc`) in transit.
- `location-picker`'s `POST /set` endpoint simply **stores the coordinate that will be returned to your iPhone**. A Shortcut can call that endpoint directly — so you can change the coordinate without opening the web UI.
- After the coordinate changes, iPhone keeps using its **cached location** until something forces a fresh request:
  - Shortcuts **cannot** toggle the "Location Services" master switch (no such action in iOS).
  - Shortcuts **can** toggle **Wi-Fi / Airplane Mode**. Since `wloc` positioning relies on Wi-Fi/cell scans, toggling one usually forces iPhone to re-request → the proxy rewrites it → new location.
- ⚠️ **Honest caveat**: the Wi-Fi/Airplane trigger is **not 100% instant** and varies by iOS version; occasionally you still need to **manually toggle Location Services once**. It removes most manual steps, not all.

---

## Prerequisites

1. `location-picker` deployed (Cloudflare Worker or self-hosted) — you have the **Worker URL** and **TOKEN**.
2. Proxy module already configured with `configUrl`, MITM on, CA cert trusted (see the repo's main guides).
3. The built-in **Shortcuts** app.

> First open `https://your-worker/loc.json?token=YOUR_TOKEN` in a browser to confirm the endpoint works, then build the Shortcut.

---

## 1. Single-location Shortcut (simplest)

Shortcuts app → **＋** → add these actions in order:

1. **Get Contents of URL**
   - **URL**: `https://your-worker.workers.dev/set?token=YOUR_TOKEN`
   - Tap **Show More**
   - **Method**: `POST`
   - **Request Body**: **JSON**, add fields:
     | Key | Type | Value |
     |------|------|------|
     | `lat` | Number | `25.0339` (your latitude) |
     | `lng` | Number | `121.5645` (your longitude) |
     | `altitude` | Number | optional |
     | `horizontalAccuracy` | Number | optional, e.g. `10` |
     | `verticalAccuracy` | Number | optional, e.g. `20` |
   - (A JSON body usually sets `Content-Type: application/json` automatically; if it errors, add the header manually.)

2. **Set Airplane Mode** → **On**
3. **Wait** → **2** seconds
4. **Set Airplane Mode** → **Off**

   > Alternative: use **Set Wi-Fi** Off → Wait 2s → On. Pick whichever trigger works better on your device.

5. (Optional) **Show Notification** → "Switched to Taipei 101"

Name it (e.g. "Loc → Taipei") and save.

### Binding (pick any)

- **Home Screen icon**: Shortcut → Share → **Add to Home Screen**.
- **Back Tap**: Settings → Accessibility → Touch → **Back Tap** → Double/Triple Tap → pick this Shortcut.
- **Action Button** (iPhone 15 Pro and later): Settings → Action Button → Shortcut.
- Lock Screen / Home Screen widget, or ask Siri by name.

## 2. Multi-location menu

1. First action: **Choose from Menu** with items `Home`, `Work`, `Taipei 101`, `Tokyo Tower`…
2. In **each** menu branch, put the 3 actions from section 1 (Get Contents of URL + Airplane toggle) with that place's `lat`/`lng`.
3. Save and bind to Back Tap / Home Screen — one tap pops the menu.

Handy coordinates (latitude first, longitude second):

| Place | lat | lng |
|------|------|------|
| Beijing Tiananmen | 39.9087 | 116.3975 |
| Shanghai Bund | 31.2397 | 121.4900 |
| Taipei 101 | 25.0339 | 121.5645 |
| Tokyo Tower | 35.6586 | 139.7454 |

## 3. Troubleshooting

**Changed but nothing happens? Check in order:**

1. Open `https://your-worker/loc.json?token=YOUR_TOKEN` — did the coordinate change?
   - **Yes** → endpoint works; it's a trigger/cache issue: manually toggle **Settings → Privacy & Security → Location Services** off 10s then on, and open Maps.
   - **No** → the request failed: check **URL, TOKEN, `lat`/`lng`** and that Method is POST.
2. If Wi-Fi toggling doesn't trigger, use Airplane Mode instead (or both).
3. Confirm the proxy module's `configUrl` is added, MITM on, CA cert set to "Full Trust".
4. Shortcut network failure: confirm the phone is online; some corporate networks / iCloud Private Relay occasionally block it.

---

## 4. Security

- The Shortcut **contains your TOKEN — it's a password**. Don't share the Shortcut, screenshots, or iCloud links (iCloud links embed the TOKEN).
- Use it only on your own device; if you rotate the TOKEN, update the Shortcut's URL.

---

## Bonus: Personal Automation (optional)

Under **Shortcuts → Automation** you can auto-run the Shortcut when you **arrive at a place**, **join a Wi-Fi network**, or at a **time of day**. Turn off "Ask Before Running" in the automation settings for a fully hands-off switch.
