# 把定位分享給朋友（多人版）

一個 picker 部署，就能分享給多位朋友，**每個人各自一份獨立的定位、互不干擾**。朋友端**不用 Surge、不用電腦**，只要一支 iPhone + 便宜的 Shadowrocket（小火箭）。

> 前提：你已經照 [`../使用教程.md`](../使用教程.md) 部署好 picker（Cloudflare Worker 或自架），手上有 **Worker 網址** 和 **TOKEN**。

---

## 原理：網址加 `&u=名字` 就是一個獨立定位

- 同一個 picker，網址後面加上 `&u=<名字>`，就會讀寫**專屬那個名字**的定位。
- 不加 `&u=`，就是你原本自己那一份，**完全不受影響**。
- 名字規則：**英文字母 / 數字 / `-` / `_`**，不分大小寫（`Alice` = `alice`），最長 32 字。

---

## 一、你要做的：發給每個朋友兩條連結

把下面的 `你的TOKEN` 換成你的，`alice` 換成這位朋友的代號（下一個朋友用 `bob`、`mom`…）：

**① 選點網頁**（朋友用它在地圖上選地點）
```
https://ios-location-picker.da70168.workers.dev/?token=你的TOKEN&u=alice
```

**② configUrl**（朋友貼進 Shadowrocket 模組，讓手機去讀座標）
```
https://ios-location-picker.da70168.workers.dev/loc.json?token=你的TOKEN&u=alice
```

> 兩條只差在 `/`（網頁）和 `/loc.json`（資料），**別填錯**。

⚠️ **共用 TOKEN 的小提醒**：所有朋友共用同一組 TOKEN，所以只要知道對方的 `u=` 名字，理論上能改到對方那份。**朋友之間用夠了**；要嚴格隔離，就讓對方各自部署一份自己的 picker。

---

## 二、朋友要做的（只在手機上，約 10 分鐘）

**需要**：一支 iPhone + **Shadowrocket（小火箭）**（App Store 付費，約 NT$90，比 Surge 便宜很多）。

1. **匯入模組**：Shadowrocket → 底部「配置」→「模組」→ 右上「＋」→「來自 URL」，貼：
   ```
   https://raw.githubusercontent.com/mekos2772/ios-location-spoofer/main/ios-location-spoofer.sgmodule
   ```
2. **開 HTTPS 解密 + 裝憑證 + 完全信任**
   - 開啟「HTTPS 解密」→ 生成並安裝憑證
   - 設定 → 一般 → VPN 與裝置管理 → 安裝 Shadowrocket 描述檔
   - ⚠️ 設定 → 一般 → 關於本機 → **憑證信任設定 → 把 Shadowrocket 那個打開**（**90% 的人漏這步，漏了就改不了**）
3. **填 configUrl**：Shadowrocket → 配置 → 模組 →「iOS Location Spoofer」→ 在 `argument=` 那行**最後面加上**你給的第 ② 條連結：
   ```
   &configUrl=https://ios-location-picker.da70168.workers.dev/loc.json?token=你的TOKEN&u=alice
   ```
   （一定要 `/loc.json`，**不是** `/`）→ 儲存
4. **開總開關**：回首頁，把上方總開關打開（會跳出允許加入 VPN，按允許）
5. **選地點**：打開你給的第 ① 條「選點網頁」→ 在地圖上選 → 按綠色「儲存定位」
6. **生效**：設定 → 定位服務 → 關 → 等 10 秒 → 開 → 打開地圖 App

> 完整圖文步驟（含各版本 Shadowrocket 介面差異）看 [`../使用教程.md`](../使用教程.md)。

---

## 三、改了沒反應？照這順序查（都是我們踩過的坑）

1. **configUrl 是 `/loc.json` 不是 `/`** — 填成 `/` 會讀到網頁、解析失敗，定位卡在美國加州預設值
2. **憑證有沒有「完全信任」**（第 2 步最後那個開關）
3. **飛航模式 ON + WiFi 開 + 躲室內** — 這方法只改 WiFi 定位，**戶外真 GPS 會蓋過去**跳回原地
4. **改完等約 60 秒**，或**關開兩次**定位服務（座標有快取，約 5 分鐘）
5. 把模組 `debug` 改 `true`，看 Shadowrocket 日誌有沒有 `remote config loaded -> 你的座標`；有就代表讀到了

---

## 安全

- **TOKEN 等於密碼**：連結別公開貼（論壇、群組、截圖都算）。
- 想讓某個朋友停用 / 全部重來：在 Cloudflare 換一組新 TOKEN，再把新連結發給還要用的人即可。
